# QOVYNT — Your Life. Your Space.

> **QOVYNT** (โค-วินท์) คือระบบปฏิบัติการจัดการชีวิตส่วนบุคคล (Personal Life Operating System) ดีไซน์สไตล์ Cyber Dark Violet / Glassmorphism ที่ออกแบบมาเพื่อให้ลื่นไหลที่สุด สวยงามระดับโมเดิร์น และพร้อมให้ทุกคนเข้าใช้งานผ่าน **GitHub Pages** ได้ทันที พร้อมระบบฐานข้อมูลและเข้าสู่ระบบด้วย Google

---

## 🌟 ฟีเจอร์หลักทั้ง 7 โมดูล + ส่วนเสริม

1. **Overview (ภาพรวมชีวิตและข้อมูลสำคัญ)**
   - 4 การ์ดสถิติสำคัญ: รายรับเดือนนี้, รายจ่ายเดือนนี้, เงินคงเหลือ, เป้าหมายการออม (%)
   - กราฟเส้นเปรียบเทียบ รายรับ vs รายจ่าย (Smooth curve neon green/rose)
   - กราฟโดนัทสรุปสัดส่วนรายจ่ายตามหมวดหมู่
   - รายการธุรกรรมล่าสุด แยกแท็บ (ทั้งหมด / รายรับ / รายจ่าย)
   - รายการเป้าหมายชีวิตและโปรเจกต์ที่กำลังทำ
   - ปฏิทินขนาดเล็ก, วิดเจ็ตข้อความสร้างแรงบันดาลใจ (Starry Mountain Quote)
   - Quick Access ทางลัด 4 ปุ่ม: เพิ่มรายรับ/จ่าย, สร้างงานใหม่, เพิ่มบันทึก, ตั้งเป้าหมาย
   - วิดเจ็ตงานที่ต้องทำ (Tasks) และตารางเวลากิจกรรมประจำวัน (Today's Agenda)

2. **Finance (การเงินและรายรับ-รายจ่าย)**
   - บันทึกรายรับ รายจ่าย เงินคงเหลือ บันทึกวันและเวลาอย่างละเอียด (Timestamp)
   - ระบบค้นหาและตัวกรองหมวดหมู่
   - กราฟแท่งเปรียบเทียบรายสัปดาห์
   - ส่งออกข้อมูลเป็นไฟล์ CSV สำหรับ Excel / Google Sheets ได้ในคลิกเดียว

3. **Tasks (งานที่ต้องทำ)**
   - สลับมุมมองได้ทั้งแบบ **List View** และ **Kanban Board** (ยังไม่เริ่ม, กำลังทำ, เสร็จแล้ว)
   - จัดลำดับความสำคัญ (สูง, ปานกลาง, ทั่วไป) และกำหนดส่ง (Due Date)
   - แบ่งหมวดหมู่งาน: เรียน, สุขภาพ, พัฒนาตัวเอง, การเงิน, งาน

4. **Calendar (ปฏิทินส่วนตัว)**
   - ปฏิทินรายเดือนแบบ Interactive พร้อมจุดแสดงนัดหมาย
   - คลิกเลือกดูตารางเวลาและกิจกรรมในแต่ละวัน
   - เพิ่มนัดหมายพร้อมระบุเวลาเริ่ม-สิ้นสุด หมวดหมู่ และธีมสี

5. **Goals (เป้าหมายและความคืบหน้า)**
   - ตั้งเป้าหมายการเงิน, สุขภาพ, การอ่านหนังสือ หรือการพัฒนาตนเอง
   - แสดงแถบ Progress Bar และจำนวนที่เหลือ
   - ปุ่มบันทึกความคืบหน้าแบบรวดเร็ว (+฿500, +1 เล่ม)
   - เอฟเฟกต์พลุเฉลิมฉลอง (Confetti) เมื่อบรรลุเป้าหมาย 100%!

6. **Notes (บันทึกส่วนตัว)**
   - พื้นที่จดบันทึกไอเดีย สิ่งที่ได้เรียนรู้ และข้อความสำคัญ
   - ปักหมุดบันทึกสำคัญไว้ด้านบน (Pin)
   - แยกสีการ์ดบันทึก และค้นหาข้อความได้ทันที

7. **Projects (โปรเจกต์ที่กำลังทำ)**
   - ติดตามโปรเจกต์ส่วนตัว พร้อมระบุขั้นตอน (Stage) เช่น พัฒนา UI, ออกแบบฐานข้อมูล, เขียนโค้ด
   - แถบปรับเปอร์เซ็นต์ความคืบหน้าแบบเรียลไทม์

8. **Habits & Daily Streak (ส่วนเสริม)**
   - ตัวติดตามพฤติกรรมและกิจวัตรประจำวัน พร้อมนับจำนวนวันที่ทำติดต่อกัน (Streak)

## 🚀 วิธีนำขึ้น GitHub Pages ให้ทุกคนเข้าใช้งานได้ (ฟรี 100%)

คุณสามารถใช้ GitHub เป็นโดเมนและพื้นที่โฮสต์เว็บได้ฟรี โดยมีขั้นตอนง่ายๆ ดังนี้:

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. เข้าไปที่ [GitHub.com](https://github.com) แล้วล็อกอินบัญชีของคุณ
2. คลิกปุ่ม **New** เพื่อสร้าง Repository ใหม่
3. ตั้งชื่อ Repository เช่น `qovynt`
4. เลือกระดับเป็น **Public** (เพื่อให้ทุกคนเข้าชมได้) แล้วกด **Create repository**

### ขั้นตอนที่ 2: อัปโหลดโค้ดขึ้น GitHub
เปิด Terminal / PowerShell ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
git init
git add .
git commit -m "Initial commit of QOVYNT Life OS"
git branch -M main
git remote add origin https://github.com/<ชื่อ-username-ของคุณ>/qovynt.git
git push -u origin main
```

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ในหน้า GitHub Repository ของคุณ ให้คลิกที่แท็บ **Settings**
2. ในเมนูด้านซ้าย ให้คลิกที่ **Pages**
3. ตรงหัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** และโฟลเดอร์ **/ (root)**
4. คลิกปุ่ม **Save**
5. รอประมาณ 1-2 นาที คุณจะได้ URL ประจำตัว เช่น:
   👉 **`https://<ชื่อ-username-ของคุณ>.github.io/qovynt/`**
   สามารถส่งลิงก์นี้ให้เพื่อนๆ หรือทุกคนเข้าใช้งานได้ทันที!

## 🗄️ การเชื่อมต่อ Cloud Database & Google Login (Supabase)

เว็บ QOVYNT ออกแบบมาให้ทำงานได้ 2 โหมด:
- **Local Storage Mode**: ทำงานได้ทันทีโดยไม่ต้องตั้งค่าใดๆ ข้อมูลจะถูกบันทึกลงเบราว์เซอร์ของผู้ใช้แต่ละคน เหมาะสำหรับการทดลองใช้งานหรือ Demo
- **Cloud Database Mode (Supabase)**: บันทึกข้อมูลลงฐานข้อมูล PostgreSQL บนคลาวด์ พร้อมระบบล็อกอินด้วย Google OAuth และ Email/Password สำหรับผู้ใช้หลายคน

### วิธีเปิดใช้งาน Supabase (ฟรี):
1. สมัครบัญชีฟรีที่ [supabase.com](https://supabase.com) แล้วสร้างโปรเจกต์ใหม่
2. ไปที่เมนู **SQL Editor** ในแดชบอร์ดของ Supabase
3. เปิดไฟล์ `supabase_schema.sql` ในโปรเจกต์นี้ คัดลอกโค้ดทั้งหมดไปวางใน SQL Editor แล้วกด **Run**
4. ไปที่เมนู **Authentication** → **Providers**:
   - คลิกที่ **Google** แล้วเปิดใช้งาน (Enabled) พร้อมใส่ Google Client ID / Secret จาก Google Cloud Console
5. ไปที่ **Project Settings** → **API**:
   - คัดลอก **Project URL**
   - คัดลอก **anon public key**
6. เปิดเว็บ QOVYNT เข้าไปที่เมนู **Settings** แล้วนำ URL และ API Key มากรอก แล้วกด **บันทึกและเชื่อมต่อ**!
